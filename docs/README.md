# Docs index

Everything here is supporting material. Start with the root
[`README.md`](../README.md) and [`ARCHITECTURE.md`](../ARCHITECTURE.md) —
those two are the maintained, current reference.

- **`design/`** — the original design-system source documents
  (`PRODUCT_DESIGN.md`, `UX_BLUEPRINT.md`). What's implemented lives in
  [`../src/ui/shared/tokens.css`](../src/ui/shared/tokens.css) and friends,
  which cite these files by section number.
- **`history/`** — archived, point-in-time records: the phase-by-phase
  `DEVELOPMENT.md` log and the one-time `MIGRATION.md` (Kite Connect →
  personal API). Historical, not maintained.
- **`research/`** — standalone research notes (regime/pattern audits, scope
  docs) referenced from tool docstrings in `src/`.
- **`CREDENTIALS.md`**, **`TOOLS.md`**, **`OPERATIONS.md`** — operational
  reference pulled out of the root README to keep it a front door rather
  than a manual.
