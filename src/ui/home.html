Security model

    

      

        Free tools — no auth
        Market data, technicals, options analytics, dashboards. Any agent can call them with no credentials.
      

      

        Personal tools — API key
        Portfolio, orders, journal, recommendations. Require your Bearer token. Each user sees only their own data.
      

      

        Token stays server-side
        Your Bearer token is sent in the HTTP header, not in chat or tool arguments. The AI model never sees it.
